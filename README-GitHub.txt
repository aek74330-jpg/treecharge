TREE CHARGE — ทำเป็นแอปบนมือถือด้วย GitHub Pages
================================================
1) เปิด config.js แก้บรรทัด APP_URL ใส่ลิงก์ /exec ของคุณ (ลิงก์จาก Apps Script → Deploy → เว็บแอป)
2) GitHub → New repository → ตั้งชื่อ เช่น treecharge → Public → Create
3) Add file → Upload files → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ icons) → Commit
4) Settings → Pages → Branch: main / (root) → Save → รอ 1–2 นาที
5) ลิงก์ที่ได้:
   ลูกค้า     https://ชื่อคุณ.github.io/treecharge/
   แอดมิน    https://ชื่อคุณ.github.io/treecharge/admin.html
   แฟรนไชส์  https://ชื่อคุณ.github.io/treecharge/partner.html
6) บนมือถือเปิดลิงก์ด้วย Chrome → ⋮ → ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก
   iPhone: Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
   → ได้ไอคอนโลโก้ TREE CHARGE เปิดเต็มจอ ไม่มีแถบเบราว์เซอร์
